# SVGの視認性修正（2026-10-22）

取得状況がpartial・unknownの区間を点線にする処理、14日図の丸印、unknownかつ記録上0件の日に線を分断する処理により、系列を追いにくくなっていた。

`scripts/civitrends/rendering.py`で、各系列を1本の連続した実線として描画し、通常は丸印を出さないようにした。1日・1週しかない図は短い横線で件数を示す。`scripts/civitrends/exports.py`も全期間で丸印を無効にする。集計処理・件数・期間・表示系列・配色は維持する。

線は記録済みの公開件数を示す。0は「記録上0件」であり、実際の公開がなかった証明ではない。取得状況の背景色（薄黄: partial、薄灰: unknown）と注記を維持し、公開日が欠けたデータを0件として追加することもない。以前の「unknown日は線を切る」という表示方針を、この記録件数の表示へ変更する。
